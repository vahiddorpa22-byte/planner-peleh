﻿# چک‌لیست انتشار نسخه‌ی بتا (فقط حساب وحید) — به ترتیب

**هیچ‌کدوم از این مراحل انجام نشده. هر مرحله فقط با «بله»ی وحید.**

## پیش‌نیاز
- سایت `app.pelehapp.ir` و `api.pelehapp.ir` هر دو روی **یک سرور** هستن (IP `79.127.54.32`، nginx 1.24 روی Ubuntu، همون سرور ایران). پس «آپلود روی هاست وب» و «آپلود روی سرور ایران» **یه کاره**.
- مسیر پوشه‌ی سایت روی سرور رو خود وحید می‌دونه (در zip نیست). برای پیدا کردنش روی سرور: `grep -R "app.pelehapp.ir" /etc/nginx/sites-enabled/` و خط `root` رو نگاه کن.
- قبل از هر چیز بکاپ بگیر (مرحله‌ی ۱).

## ۱) بکاپ (روی سرور، با PuTTY)
```
cd <مسیر سایت>
sudo tar czf ~/peleh-web-backup-$(date +%F-%H%M).tgz index.html coach.html admin.html sw.js
```

## ۲) آپلود فایل‌های وب (WinSCP/FileZilla با SFTP، یا scp)
همه‌ی محتوای پوشه‌ی `1_web_root/` رو در **ریشه‌ی سایت** کپی کن (پوشه‌ها همون‌طور):
- تازه: `peleh-beta-gate.js`، `peleh-beta.js`، `peleh-beta.css`، `coach-beta.js`، `admin-cohort.js`، پوشه‌ی `lam/`، پوشه‌ی `exercise-demos/`
- جایگزین: `index.html`، `coach.html`، `admin.html`، `sw.js`
- `app.js`، `coach-plus.js`، `peleh-app.css`، `books.js`، `health.js` و بقیه **دست نمی‌خورن**.
- ترتیب پیشنهادی: اول فایل‌ها و پوشه‌های تازه، آخر از همه چهار فایل جایگزین (تا هیچ لحظه‌ای index.html به فایلی که هنوز نرسیده اشاره نکنه).
- دسترسی فایل‌ها: `sudo chmod -R a+rX <مسیر سایت>/lam <مسیر سایت>/exercise-demos`

## ۳) تست فوری (۵ دقیقه)
1. در مرورگر کامپیوتر (حالت ناشناس، بدون ورود): `https://app.pelehapp.ir/peleh-beta.js` باید باز بشه (۲۰۰).
2. با یه حساب **غیر از** حساب وحید (یا بدون ورود): همه‌چیز باید مثل قبل باشه؛ هیچ کارت «بتا»، «لَم» یا «امروز فقط یه پله» نباید دیده بشه.
3. روی آیفون وحید (PWA از Home Screen): اپ رو ۲ بار کامل ببند و باز کن (Service Worker تازه). تنظیمات ← بالای صفحه باید «🧪 بتا (فقط حساب تو)» بیاد.
4. اولین بار یه پنجره‌ی «سطح … کتاب لَم» ممکنه بیاد (سطح فعلی از روی ثبت‌های کتاب) — طبیعیه.

## ۴) تابع سرور `send-fixed-reminders` (Supabase، جدا از سرور ایران)
- این تابع روی سرور ایران نصب نیست (فهرست توابع پکیج failover رو چک کردم)؛ فقط Supabase.
- فایل: `2_edge_function/send-fixed-reminders/index.ts`
- deploy (یکی از دو راه):
  - داشبورد Supabase ← Edge Functions ← send-fixed-reminders ← Edit ← کل متن رو با این فایل جایگزین ← Deploy. «Verify JWT» خاموش بمونه (مثل الان).
  - یا CLI: `supabase functions deploy send-fixed-reminders --no-verify-jwt --project-ref gzcwtrqysjedwdfmhbzx`
- یا به Claude بگو «deploy کن»؛ با ابزار Supabase می‌تونم همین فایل رو deploy کنم (فقط با تأیید صریح تو).
- secrets، کرون (cron-job.org هر دقیقه) و جدول‌ها **هیچ تغییری** لازم ندارن.
- تست: ساعت ۱۷:۰۰ تهران، در Supabase ← Edge Functions ← Logs باید خط `send-fixed-reminders beta {...}` بیاد و بقیه‌ی کاربرها مثل همیشه پیام ۱۷:۰۰ رو بگیرن. ساعت انتخابی وحید الان «عصر ۱۸:۳۰» هست؛ اگه تا ۱۸:۳۰ تیک نزده باشه، نوتیف «یه پله‌ی امروز» میاد. اگه «آخر شب ۲۱:۳۰» رو انتخاب کنه، ساعت ۲۱:۳۰.

## ۵) بازار
هیچ کاری. اپ اندروید فایل‌های وب رو داخل خودش داره؛ تا آپدیت آخر آبان چیزی عوض نمی‌شه.

## ادغام با اصلاح SMS (هنوز منتشر نشده)
- فایل مشترک فقط `sw.js` (اسم کش). اونی که **دوم** منتشر می‌شه باید `CACHE_NAME = "peleh-v26"` بذاره.
- اصلاح SMS به `index.html` دست نمی‌زنه؟ اگه زده، تغییر سه خط بالای این بسته (۲ تگ script + ۱ تگ link) رو روی نسخه‌ی SMS هم بذار.

## باز کردن برای همه (بعداً، وقتی وحید گفت)
- وب: در `peleh-beta-gate.js` فقط `PELEH_BETA_ALL = true` → آپلود همین یه فایل.
- سرور: در تابع، مسیر legacy رو با منطق بتا جایگزین می‌کنیم (یه تغییر کوچیک که اون موقع آماده می‌کنم).

# برگشت (Rollback)

### وب — سریع‌ترین (۱ دقیقه، بدون حذف چیزی)
در `peleh-beta-gate.js` لیست رو خالی کن: `var PELEH_BETA_USERS = [];` و آپلود. همه (حتی وحید) نسخه‌ی live رو می‌بینن.

### وب — کامل
فایل‌های پوشه‌ی `rollback/web_root/` (نسخه‌ی live امروز: `index.html`، `coach.html`، `admin.html`، `sw.js`) رو دوباره آپلود کن، یا از بکاپ مرحله‌ی ۱:
```
cd <مسیر سایت> && sudo tar xzf ~/peleh-web-backup-<تاریخ>.tgz
```
فایل‌های تازه (`peleh-beta*.js/css`، `coach-beta.js`، `admin-cohort.js`، `lam/`، `exercise-demos/`) می‌تونن بمونن؛ وقتی index.html قدیمی برگرده هیچ‌جا لود نمی‌شن.
نکته: `sw.js` قدیمی اسم کش `peleh-v24` داره؛ برگشتش کش‌ها رو یه‌بار دیگه تازه می‌کنه (بی‌خطر).

### تابع سرور
`rollback/edge_function/send-fixed-reminders/index.ts` = نسخه‌ی ۶ فعلی (همون که الان روی Supabase هست) → همون روش مرحله‌ی ۴ deploy کن.

### داده
نسخه‌ی بتا فقط در پروفایل وحید یه کلید `data.beta` می‌سازه (`sport`، `lamMax`، `bmiFigure`، `returnSkip`) و ساعت یادآوری می‌تونه `late` بشه. هیچ جدول یا ستونی اضافه نشده. اگه لازم شد، وحید از تنظیمات ساعت یادآوری رو به یکی از ۴ ساعت قبلی برمی‌گردونه.
