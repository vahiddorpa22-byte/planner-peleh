# پروژه‌ی اندروید پله (Capacitor)

## چی داخل این پروژه‌ست
- `www/` — همون کد وب پله (نسخه‌ی v18) که داخل اپ بسته‌بندی شده؛ دیگه نیازی به دامنه‌ی زنده برای *باز شدن اپ* نیست.
- `android/` — پروژه‌ی واقعی اندروید، مستقیم با Android Studio باز می‌شه.
- `capacitor.config.ts` — تنظیمات اصلی (Package ID فعلاً: `ir.pelehapp.app`، اسم اپ: پله).

یک اصلاح کوچک هم روی `app.js` انجام شد: ثبت service worker فقط وقتی اجرا می‌شه که اپ داخل مرورگر/وب باز شده باشه، نه داخل اپ native (تا با پوش نوتیفیکیشن native بعداً تداخل نکنه).

## راه‌اندازی روی سیستم خودت (اولین بار)
پیش‌نیاز: Node.js (نسخه ۱۸ به بالا) و Android Studio (با Android SDK نصب‌شده از داخل خودش).

```bash
cd peleh-capacitor
npm install
npx cap sync android
npx cap open android
```

دستور آخر مستقیم Android Studio رو با این پروژه باز می‌کنه. صبر کن Gradle Sync تموم بشه (اولین بار ممکنه چند دقیقه طول بکشه).

## تست روی گوشی/شبیه‌ساز
داخل Android Studio دکمه‌ی ▶ Run رو بزن. اگه گوشی واقعی وصل می‌کنی، حتماً "USB debugging" رو در تنظیمات Developer گوشی فعال کن.

## ساخت خروجی برای بازار/مایکت (APK امضاشده)
1. منوی Build → Generate Signed Bundle / APK
2. گزینه‌ی APK رو انتخاب کن
3. یک Keystore جدید بساز (Create new...) — **این فایل و رمزهاش رو در جای امن نگه دار، هر آپدیت بعدی پله باید با همین کلید امضا بشه.**
4. Build Variant: release
5. خروجی در `android/app/release/app-release.apk` قرار می‌گیره — همینو مستقیم توی پنل بازار و مایکت آپلود کن.

## ساخت خروجی برای گوگل پلی (AAB)
همون مسیر بالا، فقط به‌جای APK گزینه‌ی **Android App Bundle** رو انتخاب کن.

## نکات مهم قبل از انتشار نهایی
- **آدرس Supabase و کلید anon داخل app.js هاردکد شده.** همین الان هم قابل انتشاره چون کلید anon عمومیه و امنیتش با RLS سمت Supabase تأمین می‌شه — فقط مطمئن شو RLS همه‌ی جدول‌ها درست تنظیم شده.
- کتابخانه‌ی `@supabase/supabase-js` الان از CDN (`unpkg.com`) لود می‌شه؛ یعنی هر بار باز شدن اپ به اون CDN هم نیاز داره. برای اپ نهایی بهتره این کتابخانه رو لوکال کنیم (npm install کنیم و داخل www بسته‌بندی بشه) تا وابستگی کمتری به CDN بیرونی داشته باشه — می‌تونم این کارو هم برات انجام بدم.
- خرید هاست ایران و لایو شدن pelehapp.ir هیچ وابستگی‌ای برای این مرحله نداره؛ چون کل UI از داخل خود APK لود می‌شه، نه از وب‌سایت. فقط ارتباط با Supabase (که از قبل لایو و روی اینترنت جهانیه) لازمه — که اونم مستقل از هاست ایرانیته.
- برای پوش نوتیفیکیشن native واقعی (به‌جای وب‌پوش فعلی)، مرحله‌ی بعدی نصب پلاگین `@capacitor/push-notifications` + تنظیم Firebase Cloud Messaging هست — هروقت آماده بودی بگو تا اضافه‌اش کنم.
